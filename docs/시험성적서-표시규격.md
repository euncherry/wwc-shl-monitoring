## ① 전원 상태 (ON / OFF)

### 판정 근거

전원이 인가되어야만 기기가 AWS IoT Core(MQTT 브로커)에 연결되므로, 브로커가 실시간 자동 감지한 연결 상태(`connection_status`)를 전원 판정의 확정 지표로 사용한다 — **OFFLINE이 아니면 전원 ON, OFFLINE이면 전원 OFF**. 단 이 판정은 **설치·프로비저닝이 완료된 기기(`status = ACTIVE`)** 를 대상으로 하며, 아직 최초 연결 전인 `PENDING` 기기는 **'프로비저닝 대기'로 구분해 표시**한다.

### 수신 데이터

모니터링 웹은 통신을 통해 `DeviceResponseDto`의 아래 두 값을 받아 표시한다.

| `status` (DeviceStatus) | 의미 |
|---|---|
| `PENDING` | 화이트리스트 등록 완료, IoT 프로비저닝 대기 중 |
| `ACTIVE` | IoT Core 프로비저닝 완료, 정상 운영 중 |

| `connection_status` (ConnectionStatus) | 의미 |
|---|---|
| `OFFLINE` | 연결 끊김 |
| `ONLINE` | 정상 운영 중 |
| `UPDATING` | 펌웨어 업데이트 진행 중 |

> 전원 ON 판정에는 `ONLINE`과 `UPDATING`이 모두 포함된다(연결이 성립한 상태이므로).

### 표시 정책 (모니터링 페이지)

전원 상태를 아이콘 + 색상으로 표시한다.

| 상태 | 아이콘 | 색상·라벨 |
|---|---|---|
| 켜짐 (`ONLINE`·`UPDATING`) | 전원(⏻) 아이콘 | 🟢 초록 **"ON"** |
| 꺼짐 (`OFFLINE`) | 전원 사선(⏻⃠) 아이콘 | ⚪ 회색 **"OFF"** |
| 프로비저닝 대기 (`status = PENDING`) | 시계(🕐) 아이콘 | ⚪ 회색 **'프로비저닝 대기'** 뱃지를 전원 표시와 함께 노출 |

**관리자 페이지 — 실시간 그대로** (운영·점검용)

연결이 끊기면 **즉시** ⚪ 회색 'OFF'로 표시한다. (목록 표에서는 공간상 아이콘만, 상세 모달·모바일 카드에서는 아이콘 + 'ON/OFF' 라벨을 함께 표시)

**사용자(기관) 페이지 — 미연결 지속 시간 기준** (②·③과 동일한 3단계 정책)

| 미연결 지속 | 전원 표시 |
|---|---|
| **24시간 미만** | 🟢 초록 **"ON"** (야간 소등 같은 일상적 전원 차단은 문제로 표시하지 않음) |
| **24시간 이상** | ⚪ 회색 **"OFF"** (🔴 연결 끊김 뱃지와 함께 진짜 상태 노출) |

## ② 기기 동작 여부 (정상 작동 / 작동 중지)

### 판정 근거

연결이 끊기면 백엔드가 끊긴 시각(`disconnected_at`)을 기록하고 재연결 시 초기화하며, 이 시각으로 **미연결 지속 시간**을 계산해 기기 동작 여부를 판단한다.

### 표시 정책 (모니터링 페이지)

동작 상태를 아이콘 + 색상으로 표시한다.

| 상태 | 아이콘 | 색상·라벨 |
|---|---|---|
| 정상 작동 | 활동 파형 아이콘 | 🟢 초록 **"정상 작동"** |
| 업데이트 중 | 회전 화살표 아이콘 | 🔵 파랑 **"업데이트 중"** (펌웨어 원격 업데이트 진행) |
| 작동 중지 | 가로선(—) 아이콘 | ⚪ 회색 **"작동 중지"** |

**역할별 기준 — 관리자 4시간 / 사용자 24시간**

관리자 페이지(운영·점검용)는 연결이 끊기면 **즉시** '작동 중지'로 표시한다. 백엔드 서버는 **30분 주기로 전체 기기를 자동 점검**하여, 미연결이 **4시간** 이상 지속된 기기에 '연결 끊김' 장애 알림(긴급)을 알림센터에 자동 생성한다. 사용자(기관) 페이지는 야간 소등 같은 일상적 전원 차단이 장애로 보이지 않도록, 미연결이 **24시간** 이상 지속된 경우에만 '연결 끊김'으로 표시한다.

| 미연결 지속 | 관리자 페이지 | 사용자(기관) 페이지 |
|---|---|---|
| 4시간 미만 | 작동 중지 (즉시 반영) | 정상 작동 |
| **4시간** 이상 | 작동 중지 + 🔴 **장애 알림 생성** | 정상 작동 |
| **24시간** 이상 | 작동 중지 | 🔴 **연결 끊김** |

**장애 알림 자동 생성 (백엔드 스케줄러)**

| 항목 | 내용 |
|---|---|
| 점검 주기 | **30분** (백엔드 서버가 자동 실행) |
| 대상 | 프로비저닝 완료(`ACTIVE`) 기기 |
| 조건 | 미연결 지속 시간 ≥ 임계값(기본 4시간) |
| 결과 | **'연결 끊김'** 알림 생성 — 우선순위 **긴급** |

### 수신 데이터

모니터링 웹은 통신을 통해 `DeviceResponseDto`의 아래 값을 받아 판단한다.

| `disconnected_at` (Date \| null) | 의미 |
|---|---|
| 시각값 | 연결이 끊긴 시각 — 미연결 지속 시간 계산의 기준 |
| `null` | 연결 중 (재연결 시 초기화) |

### 장애 알림 임계값 설정

장애 알림 기준(4시간)은 고정값이 아니라 **모니터링 웹의 관리자 알림센터 → 알림 설정에서 조정할 수 있으며**, 아래 API로 연동된다. (사용자 페이지의 '연결 끊김' 표시 기준 **24시간은 화면 표시 정책으로 고정**되어 있으며, 이 설정과 무관하다.)

| API | 설명 |
|---|---|
| `GET /alerts/settings/thresholds` | 현재 임계값 조회 (관리자 전용) |
| `PATCH /alerts/settings/thresholds` | 임계값 수정 (관리자 전용) |

| `connection_lost_hours` (number) | 의미 |
|---|---|
| 시간값 (현재 **4**) | 미연결이 이 시간 이상 지속되면 '연결 끊김' 장애 알림(긴급)을 자동 생성. 최솟값 1 |

## ③ 네트워크 연결 상태 (Wi-Fi)

### 판정 근거

기기가 보고하는 Wi-Fi 신호세기 원시값(`wifi_rssi_dbm`)을 백엔드가 4단계 등급(`wifi_signal`)으로 산출하고, 모니터링 웹은 이 두 값으로 네트워크 연결 상태를 표시한다 — **강함**(RSSI ≥ -55dBm) / **보통**(-67 ~ -55dBm) / **약함**(< -67dBm) / **끊김**(연결 해제 또는 RSSI 미수신).

### 수신 데이터

모니터링 웹은 통신을 통해 `DeviceResponseDto`의 아래 두 값을 받아 표시한다.

| `wifi_signal` (WifiSignal) | 의미 |
|---|---|
| `STRONG` | 강함 — RSSI ≥ -55dBm |
| `FAIR` | 보통 — -67 ~ -55dBm |
| `WEAK` | 약함 — RSSI < -67dBm |
| `DISCONNECTED` | 끊김 — 연결 해제 또는 RSSI 미수신 |

| `wifi_rssi_dbm` (number \| null) | 의미 |
|---|---|
| 수치 | Wi-Fi 신호세기 원시값(dBm) — 등급 산출의 근거 |
| `null` | 미수신 (연결 해제 상태) |

### 표시 정책 (모니터링 페이지)

신호 등급을 Wi-Fi 아이콘 + 색상으로 표시한다.

| 등급 | 기준 | 아이콘 | 색상·라벨 |
|---|---|---|---|
| `STRONG` | RSSI ≥ -55dBm | Wi-Fi 호 3개(가득) | 🟢 초록 **"강함"** |
| `FAIR` | -67 ~ -55dBm | Wi-Fi 호 2개 | 🟢 초록 **"보통"** |
| `WEAK` | < -67dBm | Wi-Fi 호 1개 | 🟠 주황 **"약함"** |
| `DISCONNECTED` | 연결 해제·RSSI 미수신 | Wi-Fi 사선(⃠) | 🔴 빨강 **"끊김"** |

**역할별 기준 — 관리자 실시간 / 사용자 4시간·24시간**

관리자 페이지(운영·점검용)는 위 등급을 실값 그대로 표시한다. 아이콘에 등급별 색상을 적용하고 라벨과 **RSSI 원시값(dBm)** 을 함께 표시하며, 연결이 끊기면 **즉시 빨간 '끊김'**. 사용자(기관) 페이지는 연결 중에는 동일한 등급 칩(강함·보통=초록, 약함=주황)을 표시하되, 미연결 시에는 빨간 '끊김' 대신 지속 시간에 따라 단계적으로 표시한다.

| 미연결 지속 | 관리자 페이지 | 사용자(기관) 페이지 |
|---|---|---|
| 4시간 미만 | 🔴 끊김 (즉시 반영) | 🟢 초록 **"정상"** |
| **4시간** 이상 | 🔴 끊김 | ⚪ 회색 **"끊김"** (문제를 Wi-Fi 연결로만 드러냄) |
| **24시간** 이상 | 🔴 끊김 | **"—"** (🔴 연결 끊김 뱃지와 함께 진짜 상태 노출) |

> RSSI 원시값(dBm) 표시는 신호 등급 검증용으로 관리자 페이지에만 노출한다.

## 검증 방법

위 표시 규격이 실제 화면에서 그대로 구현되었음을 확인하는 전용 페이지를 제공한다.

| 항목 | 내용 |
|---|---|
| 경로 | `/status-spec` (메뉴에 노출되지 않으며 URL 직접 입력으로 접근) |
| 구성 | 관리자 뷰 / 사용자(기관) 뷰를 나란히 배치해 동일 상태에서의 표시 차이를 대조 |
| 검증 데이터 | 미연결 지속 시간별 예시 데이터(현재 시각 기준 상대 생성) — **화면에 예시 데이터임을 명시** |
| 경계값 검증 | 3시간 59분 / 4시간 1분, 23시간 59분 / 24시간 1분을 나란히 표시해 임계값 동작을 확인 |
| 실기기 현황 | 로그인 시 현재 운영 중인 실제 기기가 어느 단계에 해당하는지 함께 표시 |
| 기준 시각 | 화면에 렌더링 기준 시각을 표시하여 캡처 시점을 명확히 함 |

> 표시 규격 실증에 사용하는 예시 데이터는 임계값 동작 확인을 위한 가상 데이터이며, 화면에 그 사실이 명시된다. 실제 운영 기기의 상태는 '실기기 현황' 항목에서 별도로 확인한다.
