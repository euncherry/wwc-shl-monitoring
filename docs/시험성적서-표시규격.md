## ① 전원 상태 (ON / OFF)

### 판정 근거

- 전원 인가 시 기기가 부팅 → Wi-Fi 접속 → AWS IoT Core(MQTT 브로커) 연결을 수립한다. 브로커가 이 연결 수립/해제를 실시간 자동 감지해 백엔드 연결 상태(`connection_status`)를 갱신하며, **연결은 전원이 인가된 상태에서만 성립하므로 전원 판정의 확정 지표**로 사용한다 (연결됨 = 전원 ON).

### 표시 정책 (모니터링 페이지)

전원 상태를 아이콘 + 색상으로 표시한다.

| 상태 | 아이콘 | 색상·라벨 |
|---|---|---|
| 켜짐 | 전원(⏻) 아이콘 | 🟢 초록 **"ON"** |
| 꺼짐 | 전원 사선(⏻⃠) 아이콘 | ⚪ 회색 **"OFF"** |

**관리자 페이지 — 실시간 그대로** (운영·점검용)

연결이 끊기면 **즉시** ⚪ 회색 'OFF'로 표시한다. (목록 표에서는 공간상 아이콘만, 상세 모달·모바일 카드에서는 아이콘 + 'ON/OFF' 라벨을 함께 표시)

**사용자(기관) 페이지 — 미연결 지속 시간 기준** (②·③과 동일한 3단계 정책)

| 미연결 지속 | 전원 표시 |
|---|---|
| **24시간 미만** | 🟢 초록 **"ON"** (야간 소등 같은 일상적 전원 차단은 문제로 표시하지 않음) |
| **24시간 이상** | ⚪ 회색 **"OFF"** (🔴 연결 끊김 뱃지와 함께 진짜 상태 노출) |

## ② 기기 동작 여부 (정상 작동 / 업데이트 중 / 작동 중지)

### 판정 근거

- 연결 상태(`connection_status`)와 **연결이 끊긴 시각(`disconnected_at`)**. 연결이 끊기면 백엔드가 끊긴 시각을 기록하고, 재연결되면 초기화한다 — 이 시각으로 **미연결 지속 시간**을 계산한다.

### 표시 정책 (모니터링 페이지)

동작 상태를 아이콘 + 색상으로 표시한다. 펌웨어 원격 업데이트(OTA)가 진행 중인 기기는 별도 상태로 구분한다.

| 상태 | 아이콘 | 색상·라벨 |
|---|---|---|
| ONLINE | 활동 파형 아이콘 | 🟢 초록 **"정상 작동"** |
| UPDATING | 회전 화살표 아이콘 | 🔵 파랑 **"업데이트 중"** (OTA 진행 중) |
| OFFLINE | 가로선(—) 아이콘 | ⚪ 회색 **"작동 중지"** |

역할에 따라 다르게 표시한다.

**관리자 페이지 — 실시간 그대로** (운영·점검용)

연결이 끊기면 **즉시** 작동 중지·전원 OFF로 표시하고, WiFi는 실값 '끊김'으로 표시한다.

**사용자(기관) 페이지 — 미연결 지속 시간 기준 3단계** (야간 소등 같은 일상적인 전원 차단이 장애처럼 보이지 않도록)

| 미연결 지속 | 상태 뱃지 | 전원 / 동작 | WiFi |
|---|---|---|---|
| **4시간 미만** | 정상 | ON / 정상 작동 | 정상 |
| **4~24시간** | 정상 | ON / 정상 작동 | 회색 **"끊김"** |
| **24시간 이상** | 🔴 **연결 끊김** | OFF / 작동 중지 | — |

- 4시간은 백엔드 장애 알림(CONNECTION_LOST, `connection_lost_hours=4`) 기준과 동일한 값이며, 사용자 페이지에서 **장애(연결 끊김)로 표시하는 것은 24시간 이상 지속된 경우만**이다.

## ③ 네트워크 연결 상태 (Wi-Fi)

### 판정 근거

- 기기가 보고하는 Wi-Fi 신호세기 원시값(`wifi_rssi_dbm`)을 백엔드가 4단계 등급(`wifi_signal`)으로 산출하고, 프론트는 이 두 필드로 네트워크 연결 상태를 표시한다 — **강함**(RSSI ≥ -55dBm) / **보통**(-67 ~ -55dBm) / **약함**(< -67dBm) / **끊김**(연결 해제 또는 RSSI 미수신).

### 표시 정책 (모니터링 페이지)

신호 등급을 Wi-Fi 아이콘 + 색상으로 표시한다.

| 등급 | 기준 | 아이콘 | 색상·라벨 |
|---|---|---|---|
| 강함 | RSSI ≥ -55dBm | Wi-Fi 호 3개(가득) | 🟢 초록 **"강함"** |
| 보통 | -67 ~ -55dBm | Wi-Fi 호 2개 | 🟢 초록 **"보통"** |
| 약함 | < -67dBm | Wi-Fi 호 1개 | 🟠 주황 **"약함"** |
| 끊김 | 연결 해제·RSSI 미수신 | Wi-Fi 사선(⃠) | 🔴 빨강 **"끊김"** |

**관리자 페이지 — 실시간 그대로** (운영·점검용)

위 등급 아이콘·색상을 실값 그대로 표시하고, 아이콘 옆에 RSSI 원시값(dBm)도 함께 표시한다(신호 단계 검증용 임시). 연결이 끊기면 **즉시 빨간 '끊김'**.

**사용자(기관) 페이지 — 미연결 지속 시간 기준 3단계** (①·②와 동일 정책)

연결 중에는 위 등급을 색상 칩으로 표시한다(강함·보통=초록 칩, 약함=주황 칩). 미연결 시에는 빨간 '끊김' 대신 지속 시간에 따라:

| 미연결 지속 | WiFi 표시 |
|---|---|
| **4시간 미만** | 🟢 초록 칩 **"정상"** (Wi-Fi 아이콘) |
| **4~24시간** | ⚪ 회색 칩 **"끊김"** (사선 아이콘 — 은은하게, 문제를 WiFi 연결로만 드러냄) |
| **24시간 이상** | **"—"** (🔴 연결 끊김 뱃지와 함께 진짜 상태 노출) |

## 검증 방법

위 표시 규격이 실제 화면에서 그대로 구현되었음을 확인하는 전용 페이지를 제공한다.

| 항목 | 내용 |
|---|---|
| 경로 | `/status-spec` (메뉴에 노출되지 않으며 URL 직접 입력으로 접근) |
| 구성 | 관리자 뷰 / 사용자(기관) 뷰를 나란히 배치해 동일 상태에서의 표시 차이를 대조 |
| 검증 데이터 | 미연결 지속 시간별 예시 데이터(현재 시각 기준 상대 생성) — **화면에 예시 데이터임을 명시** |
| 경계값 검증 | 3시간 59분 / 4시간 1분, 23시간 59분 / 24시간 1분을 나란히 표시해 임계값 동작을 확인 |
| 실기기 현황 | 로그인 시 현재 운영 중인 실제 기기가 어느 단계에 해당하는지 함께 표시 |
| 기준 시각 | 화면에 렌더링 기준 시각을 표시하여 캡처 시점을 명확히 함 |

> 표시 규격 실증에 사용하는 예시 데이터는 임계값 동작 확인을 위한 가상 데이터이며, 화면에 그 사실이 명시된다. 실제 운영 기기의 상태는 '실기기 현황' 항목에서 별도로 확인한다.
