공공시설에 설치된 히어링루프 장비의 상태를 실시간으로 모니터링하고 관리하는 웹 기반 플랫폼입니다.

# 사용자 역할
시스템은 **관리자(Admin)** 와 **사용자(User)** 두 가지 역할로 구분됩니다.

| **구분** | **역할** | **데이터 범위** | **메뉴 구성** |
| --- | --- | --- | --- |
| **관리자** | 전체 텔레코일존과 히어링루프를 통합 운영 | 전체 기관·기기 | 대시보드, 히어링루프 관리, 텔레코일존 관리, 펌웨어 관리, 알림센터 |
| **사용자** | 소속 기관의 히어링루프를 모니터링 | 소속 기관의 기기만 | 대시보드, 히어링루프 관리, 정보관리, 기술 지원 |

## 핵심 개념

### 텔레코일존 = 기관

텔레코일존과 기관은 동일한 단위입니다. 역할에 따라 부르는 명칭이 다릅니다.

- **관리자** 시점 : 여러 기관을 관리하므로 **"텔레코일존"** 이라 부름
- **사용자** 시점 : 본인이 속한 하나의 기관이므로 **"우리 기관"** 이라 부름

### 별칭(alias) 시스템

히어링루프 기기에 사용자가 별칭(`alias`)을 부여할 수 있습니다.

- 별칭이 지정된 경우 : **별칭**이 메인 타이틀, MAC 주소가 서브 태그로 표시
- 별칭이 미지정인 경우 : **MAC 주소**가 메인 타이틀로 표시 (동일한 레이아웃)

# 로그인
- 아이디 / 비밀번호 입력
- 비밀번호 표시/숨김 토글
- 역할에 따라 관리자(/admin) 또는 사용자(/user) 화면으로 자동 분기
- 로그인 실패 시 에러 메시지 표시

# 관리자

## 히어링루프 관리
1. **히어링루프 등록( 기기 추가 )**
    1. 등록할 히어링루프 MAC주소 입력
2. **전체 히어링루프 리스트**
    - 개별 히어링루프 상세보기
        - **개별 히어링루프 상태 정보 보기**
            - **전원상태**
            - **기기 동작 여부**
            - 온도 (제어 x)
            - 볼륨 (제어 x)
            - **네트워크 정상 연결**
        - **개별 히어링루프 상세 정보 보기**
            - 펌웨어 버전
            - 배치된 텔레코일 존
            - MAC 주소
        - **기기 삭제**
        - **개별 히어링 루프 별칭 변경**

## 텔레코일존 관리
1. **텔리코일 존 등록**
    1. [ 텔레코일 존 이름 , 담당자 이메일 , 사용자 계정 생성] 입력
2. **전체 텔레코일존 카드 그리드 리스트**
3. **텔레코일별 상세보기**
    1. 담당자 이메일 수정
    2. 사용자 모드 계정 관리 (ID / PW 수정 및 조회)
    3. 배정된 히어링루프 목록 조회
    4. 히어링루프 추가 배정 및 삭제
    5. 알림 이력 확인
    6. 텔레코일존 삭제

## 펌웨어 관리
1. 펌웨어 추가
    1. [펌웨어 파일 , 펌웨어 버전 , 간단 설명] 입력
2. 펌웨어 업데이트
    1. 개별·전체 펌웨어 업데이트

## 알림센터
- KPI 카드 (전체 알림, 처리 대기, 긴급 알림, 오늘 발생)
- 처리 상태 탭 : 처리 대기 / 사용자에게 전달됨 / 관리자 종결 / 전체
- 유형 필터 (온도 이상, 전원 차단, 볼륨 이상, 연결 끊김, 펌웨어 업데이트 필요)
- 우선순위 필터 (긴급, 경고, 정보)
- 알림 상세 모달 (사용자에게 전달 / 무시·종결)
- 일괄 전달 및 일괄 종결
- 알림 설정 (온도·볼륨 임계값, 알림 그룹핑, 자동 에스컬레이션 시간)

# 사용자

## 대시보드

> 소속 기관 히어링루프의 전체 현황 파악

- 환영 배너 (기관명, 기기 수, 가동 수, 오늘 알림 수)
- 기관 히어링루프 KPI (전체 / 정상 가동 / 오프라인 / 경고)
- 가동률 프로그레스 바
- 장비별 실시간 상태 목록 (전원, 네트워크, 상태 뱃지)
- 오늘 발생 알림 요약
- 시스템 상태 메시지
- 최근 알림 시간 및 통계

## 히어링루프 관리
> 소속 기관 히어링루프의 상태 조회 및 별칭 관리

- 상태 KPI 카드 (전체, 정상, 경고, 오류/오프라인)
- 별칭, MAC 주소 검색
- 기기 카드 목록 (전원·네트워크·동작 상태 표시)
- 기기 상세 모달
  - 별칭 편집
  - 전원·네트워크·기기 동작 상태 조회
  - 텔레코일존·MAC·등록일·최종 업데이트 정보

## 정보관리
> 소속 기관 및 담당자 정보 확인·수정

- **기관 정보** : 기관명(읽기 전용), 주소(편집), 대표번호(편집)
- **담당자 정보** : 이름(읽기 전용), 이메일(편집), 부서(읽기 전용)
- 인라인 편집 (hover 시 수정 버튼 표시)

## 기술 지원
> 사용 가이드 영상 및 기술 지원 연락처

- **사용 가이드** : YouTube 영상 임베드 (썸네일 클릭 시 재생)
- **지원팀 연락처**
  - 담당자 이름
  - 전화번호 + 영업시간 표시
  - 이메일

### 해결됨
- **활동 로그(activity-log)** — 제외 확정(2026-06-04 사용자 결정). 관리자 메뉴에서 삭제. CLAUDE.md §7·§11·BACKEND §10(제외)과 일치.
- **펌웨어 관리 메뉴** — 본문에 섹션이 있어 관리자 메뉴 표에 추가함(유지 확정).
- **"기기 ID" = MAC 주소** — 별도 표시용 ID 개념 없음(2026-06-04 사용자 결정). 별칭 서브태그·검색 등 모든 "기기 ID"를 MAC으로 치환. CLAUDE.md §5(friendly ID 금지, MAC 식별)와 일치.
- **별칭 명칭 = `alias`** — "Nickname" 표기를 `alias`로 통일(2026-06-04 사용자 결정). 백엔드 실필드(`alias`, unique, `PATCH /devices/:mac`, 실연동)와 일치.
