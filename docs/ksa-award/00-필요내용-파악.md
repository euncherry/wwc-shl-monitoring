## 3. 코드베이스에서 확보 완료된 재료 (별지 2호·PPT용)

### 3-1. 제품 정의 (초안 1줄)

> **스마트 히어링루프 모니터링 시스템** (smarthearingloop.com) — 공공시설에 설치된 청각보조 히어링루프(임베디드 기기)의 전원·동작·네트워크·과열 상태를 MQTT/AWS IoT Core 기반으로 원격 수집하고, 웹에서 실시간 관제·장애 알림·원격 펌웨어 업데이트(OTA)까지 수행하는 IoT 관제 플랫폼.

### 3-2. 시스템 아키텍처 (문서·코드 근거 확보)

```
[히어링루프 기기: ESP32(Wi-Fi) + nRF(Nordic) 듀얼 MCU]
   --MQTT over TLS(기기별 인증서, protobuf 추정 · SHL MQTT Protocol 문서 v4.0 / proto v4.4)-->
[AWS IoT Core 브로커]
   ├─ 앱 메시지: IoT Rule → SQS → NestJS 백엔드(폴링)
   ├─ presence(연결/해제): lifecycle → Lambda → 백엔드 콜백 → connection_status
   └─ 하행: 백엔드 publish → 기기 (명령·OTA 알림)
[NestJS 백엔드 (AWS, staging/prod 분리, S3 펌웨어 저장, 30분 Cron 장애 점검)]
   --REST(JWT) + SSE(OTA 진행률)-->
[React 19 프론트엔드 (Vercel 배포)]
```

- 상행 MQTT 메시지 5종(문서 확인): **HelloRequest**(펌웨어 버전 보고), **StatusReport**(과열 GPIO·Wi-Fi RSSI·SSID, 이벤트 기반 발신), **ErrorReport**, **UpdateReport**(OTA 진행), **DeviceLog**
- 브로커 역할: 기기별 TLS 인증·pub/sub 중계·**presence 자동 감지**(전원/연결 판정의 근거)·Rule 라우팅

### 3-3. 기술성·독창성 소구 포인트 후보 (모두 코드/문서 근거 있음)

1. **MAC 화이트리스트 기반 무인 자동 프로비저닝** — 웹에서 MAC 등록(PENDING) → 기기 최초 접속 시 서버가 자동 인증서 발급·ACTIVE 전환. 미등록 MAC은 접속 거부. 현장 온보딩 1대당 15~20분.
2. **브로커 presence 기반 연결 판정** — 폴링·heartbeat 휴리스틱이 아니라 AWS IoT Core lifecycle 이벤트로 전원·동작·연결을 실시간 확정 (구 last_seen 5분 휴리스틱 폐기).
3. **듀얼 MCU 원격 OTA** — 릴리즈 zip 1개(update.json + ESP32/nRF 바이너리 2종) 업로드 → ONLINE 기기만 선택 전송 → **SSE 실시간 진행률(MCU 2채널 각각 %)** → 3분 무응답 타임아웃, 편측 성공 감지(`firmware_inconsistent`), 세션 이력·단계별 로그.
4. **무감시 장애 자동 감지** — 백엔드 30분 주기 스케줄러가 미연결 4시간(관리자 설정 가능 임계값) 초과 기기에 긴급 알림 자동 생성. 알림 3종(과열/연결 끊김/펌웨어 업데이트 필요) × 처리 워크플로(대기→전달→종결).
5. **역할별 표시 정책(운영 UX 설계)** — 관리자는 실시간 그대로, 기관 사용자는 야간 소등 오탐 방지를 위해 4h/24h 3단계 유예 표시. **시험성적서 표시규격 v1.5로 동결 + 전용 실증 페이지 `/status-spec`**(경계값 3h59m/4h1m·23h59m/24h1m 검증, 프로덕션 컴포넌트 그대로 렌더).
6. **과열 보호 연동** — 온도 센서 없이 GPIO 과열 경보 수신(하드웨어는 자동 출력 저감), 7일×24시간 과열 히트맵·드래그 밴드 뷰(RSSI 폴리라인 포함)로 추이 분석.
7. **관제 시각화** — 카카오맵 기기 지도뷰(상태별 마커·길찾기), Wi-Fi RSSI 분포 스트립(등급 경계 -55/-67dBm), 존별 가동률, 배치 파이프라인(프로비저닝→배정→운영) 깔때기.

### 3-4. 기능 목록 (화면 단위 — 전부 실코드 확인)

**관리자**: 대시보드(지도뷰·Wi-Fi 분포·존별 가동률·과열 롤업·배치 파이프라인) / 히어링루프 관리(9컬럼 목록·검색·존 필터·정렬 저장·일괄 등록·OTA 다중 선택·상세 모달: 존 배정/별칭/좌표/삭제/추이 히트맵/이력 6탭) / 텔레코일존 관리(카드 그리드·존+계정 생성·PW 재설정·기기 배정/해제·존 알림 이력·존 전체 OTA) / 펌웨어 관리(zip 업로드 자동 파싱·개별 전송·SSE 진행률) / 알림센터(KPI·4탭·유형/우선순위 필터·발생 기준 배너·일괄 처리·임계값 설정)

**사용자(기관)**: 히어링루프 관리(KPI·검색·카드·상세, 3단계 유예 표시) / 정보관리(이메일 실편집, 주소·전화는 목) / 기술 지원(가이드 영상·연락처) / 대시보드(⚠️ 하드코딩 목 — 서술 주의)

**공통/품질**: JWT 인증·401 자동 로그아웃, RBAC(ADMIN/ZONE_USER 서버 강제), 라우트 가드 4종, 반응형(테이블↔모바일 카드), TypeScript strict, MSW 하이브리드(실연동 전환 완료분 제외 목 2건).

## 5. 서술 시 주의 — 과장 금지 체크리스트 (심사·실사 대비)
